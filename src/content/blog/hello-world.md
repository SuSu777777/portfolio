Hi, I'm Wongfengchen. This is my space to document what I learn and build as a developer.

I'll use it to share how I approach problems, what new tools teach me, and the decisions behind my projects.

## Publishing a new post

This blog uses Markdown files. Create a new `.md` file in `src/content/blog/` and start with frontmatter like this:

```yaml
---
title: 'Your post title'
description: 'A short summary'
pubDate: 2026-10-23
---

Write your post here.
```

Save the file and deploy the site. The new post will appear in the list automatically.
